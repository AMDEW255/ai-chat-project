# Урок 10 — Сохраняем проект на GitHub

Сегодня научимся сохранять свой проект не только на компьютере, а ещё и в интернете — на GitHub. Так его не потеряешь, даже если компьютер сломается, и всегда сможешь показать другим.

У тебя уже есть:
- Аккаунт на [github.com](https://github.com) (заводили в прошлый раз)
- Папка с проектом на компьютере, в которой уже "включён" гит (наставник подскажет, если не уверена)

---

## Шаг 1 — создаём пустой домик на GitHub

1. Зайди на [github.com](https://github.com) и залогинься под своим аккаунтом
2. Справа сверху нажми на `+` → **New repository**
3. В поле **Repository name** впиши имя проекта, например `ai-chat-project`
4. Ничего больше не трогай — галочки **не ставь** (особенно "Add a README file")
5. Нажми зелёную кнопку **Create repository**

Откроется страница с инструкциями — она нам сейчас пригодится, не закрывай её.

---

## Шаг 2 — копируем адрес репозитория

На той странице, которую ты только что открыла, найди ссылку вида:

```
https://github.com/твой_логин/ai-chat-project.git
```

Нажми на иконку копирования рядом с ней (или выдели и скопируй сама).

---

## Шаг 3 — открываем терминал в папке проекта

1. Открой папку своего проекта в VS Code
2. Открой терминал: сверху меню **Terminal → New Terminal**
3. Убедись, что терминал открылся именно в папке твоего проекта (внизу командной строки должно быть её имя)

---


## Шаг 4 — сохраняем последние изменения (commit)

Прежде чем отправлять проект на GitHub, нужно сказать гиту "вот это сохрани". Введи по очереди (после каждой строки — Enter):

```bash
git add .
git commit -m "мой первый проект"
```

- `git add .` — говорит гиту "возьми все файлы в этой папке"
- `git commit -m "..."` — говорит "сохрани их вот с такой подписью" (подпись можешь написать свою)

Если гит попросит `git config user.email` и `user.name` — сначала введи (один раз, замени на свои):

```bash
git config --global user.email "твоя_почта@gmail.com"
git config --global user.name "Твоё Имя"
```

а потом повтори `git commit -m "мой первый проект"` ещё раз.

---

## Шаг 5 — подключаем адрес с GitHub

Введи команду (вставь свою ссылку из Шага 2 вместо адреса ниже):

```bash
git remote add origin https://github.com/твой_логин/ai-chat-project.git
```

Это говорит гиту: "запомни, куда отправлять проект — вот этот адрес в интернете, назовём его origin".

---

## Шаг 6 — отправляем проект (push)

```bash
git branch -M main
git push -u origin main
```

- Первая строка — называет твою "ветку" (главную линию проекта) `main`, как принято на GitHub. Она сработает, даже если у тебя ветка раньше называлась по-другому, например `master` — гит просто переименует её в `main`
- Вторая строка — и есть отправка. `-u origin main` означает "отправь в origin, в ветку main, и запомни это на будущее"

Гит может попросить залогиниться в GitHub — сделай это через окно браузера, которое откроется, или введи логин/пароль (иногда вместо пароля просит специальный код — тогда позови наставника).

---

## Шаг 7 — проверяем

Обнови страницу репозитория на github.com (та самая страница из Шага 1). Если видишь свои файлы — получилось!

---

## Важно запомнить

Как только один раз сделала Шаги 5-6 — GitHub запомнит адрес. В следующий раз, когда что-то поменяешь в проекте, нужно будет всего две команды (уже без `remote add` и `-u`):


```bash
git add .
git commit -m "что поменяла"
git push
```

Так будешь делать после каждого урока — это как сохранить прогресс в игре.

---

## Если что-то пошло не так

- **"fatal: not a git repository"** — значит гит ещё не включён в этой папке. Позови наставника, он поможет сделать `git init`.
- **Просит логин, но ничего не принимает** — GitHub больше не разрешает вход по обычному паролю через терминал, нужен специальный код (token). Позови наставника — настроим один раз.
- **"failed to push... rejected"** — на GitHub уже что-то есть (например, ты случайно поставила галочку README). Позови наставника, разберёмся вместе.

---

## ДЗ

1. Сделай в проекте любое маленькое изменение (например, поменяй текст кнопки)
2. Сохрани его на GitHub тремя командами из раздела "Важно запомнить"
3. Зайди на страницу репозитория и убедись, что изменение там появилось
